# Healthcare Platform: Concept

A clickable prototype of a healthcare management platform, designed by Liana Maiatska.

**Live demo:** https://lianauiux.github.io/healthcare-platform/

> Concept project. The clinic ("Corvina General Hospital"), patients, staff and all data are fictional.

## What's inside

- **Appointments:** today's list and calendar, status tabs, date picker for any day or week
- **Visit completion:** SOAP visit note with templates by visit reason, red flags, ICD-10 diagnoses, draft from dictation, sign & complete
- **Patient profile:** overview, visits, timeline, documents, medical history
- **Home visits:** weekly schedule, route on a map, driver and car
- **E-prescribing:** dosing, allergy check, coverage and savings, pharmacy routing
- **Analytics:** daily and weekly metrics for the physician
- **Patients:** list and card views
- **Roles:** physician, nurse, reception, administrator, management, each with its own modules
- **Languages:** English and Ukrainian

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Static HTML, CSS and JavaScript. Avatars are generated by [DiceBear](https://www.dicebear.com/).
